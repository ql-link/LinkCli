# MCPSTAT-1-CONSOLE 实施报告

## 已完成

- 新增用户名密码注册、Argon2id 摘要、HttpOnly Cookie 和 7 天滑动会话。
- 新增普通成员、审核员、运营管理员角色与最后一个运营管理员保护。
- 新增同域 `/api` 控制台接口，覆盖工作台、项目、版本、审核、调用凭据和用户角色。
- 新增 React + Vite 控制台及登录、注册、项目、审核、凭据、角色和个人账户页面。
- 版本详情固定以目标版本之前最近一个已批准版本为差异基线，避免版本发布后因与自身比较而丢失审核差异；首版与空工具集比较。
- 使用 Geist、Tailwind、GSAP 和 Phosphor Icons 落实 `gpt-taste` 视觉约束，并支持减少动态效果。
- 新增 `platform_users`、`platform_sessions` 及已有数据库的安全增量脚本。
- 保留 `/admin` 和 `/mcp` 既有契约，浏览器不接触部署级管理密钥。

## 验证

- 后端与前端 TypeScript 类型检查通过。
- 51 项自动化测试通过，包括真实开发 MySQL、标准 MCP、审核并发、登录会话和控制台登记。
- API 与前端生产构建通过。
- 增加版本发布后历史差异保持稳定的接口回归测试。
- 本地生产模式同域托管验证：根页面、注册、登录和工作台分别返回 200、201、200、200。

## 已知边界

- 登录限流为单实例内存实现，多副本部署前需要接入共享限流或入口网关限流。
- 旧管理接口创建的外部所有者标识不会自动绑定新账号，避免错误归属。
- 本期未建设采集、分析和闭环层统计页面。
